# VRMAnimationNormalizer
Vibecoded script (if you couldn't tell from the 1000 lines of code it uses) that normalizes **non-humanoid** keyframes on Animations, useful for stuff like migrating tail wag animations from VRChat to Vtuber

<img width="547" height="220" alt="image" src="https://github.com/user-attachments/assets/3198f125-f0fe-4bb0-ba2f-e1919309db36" />

## Download
* Download the .cs script and put it on your Unity Project
* Go to Tools > VRM > Normalize animation

## How to use
* Drag your original avatar under **Source Model**
* Drag your Normalized avatar under **Normalized VRM**
* Drag the animation clip you wish to normalize
* Use the same sample rate as your animation (usually 60). Check it out on the top right
